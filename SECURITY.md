# Security policy

## Reporting a problem

If you find a security problem, **please don't open a public issue.** Report it privately instead:

**[Report a vulnerability](https://github.com/sirgijoe/joe-ai/security/advisories/new)** (GitHub's private form; only the maintainer can see it)

Include what you found, how to reproduce it, and what someone could do with it. You'll get a reply as soon as possible. Once there's a fix, it ships in a new release, and you'll be credited in it unless you'd rather not be.

## What's covered

Joe's program (`joeai/`), its web interface (`joeai/ui/`), the installers (`installer/`) and the update and signing code.

Joe runs on your own computer. He uses the internet only for what the README's *When Joe uses the internet* section lists.

## Supported versions

Only the latest release gets security fixes. Please update to it before reporting.
